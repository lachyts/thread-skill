## Local checks and remaining promises

Before dispatch, a deliberately conflicting fixed-high profile was rejected for
a hard/xhigh request: “Native profile effort conflicts with requested routing;
do not silently override it.” This is explicitly a local resolver fixture,
not a live configuration migration. The current configuration stayed unchanged;
native child overrides independently demonstrated high, xhigh and ultra.
The pinned shared resolver's eight focused tests passed. Source hashes and the
clean fixture were rechecked after the probes.

The following remain unproven here:

- Genuine substantive failure followed by maximum correction, and a failed
  maximum correction followed by a configured alternative. The two maximum
  probes used synthetic selectors; they consumed real slots but no correction
  history. No alternative model is configured.
- Live rollout-host receipt capture, PR verification/merging and integrated
  post-merge checks; exact launch-authority binding and cumulative reservations.
- Stopped-owner transfer, interruption recovery, fenced old-owner operations and
  quiet continuation after a task ends.
- Claude routing/profile migration, estate-wide activation, broader release
  promises and any change to historical executions.
